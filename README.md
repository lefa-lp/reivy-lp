# REIVY Facial Wax LP

REIVY（リ・アイビー）フェイシャルワックスサロンの新規集客用ランディングページです。

Instagram・広告・SNS → LP → LINE予約 の導線を軸に設計しています。

## 構成

```
reivy-lp/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   ├── fv/            ← ファーストビュー用写真
│   ├── before-after/  ← Before/After比較写真
│   ├── treatment/      ← 施術風景写真
│   ├── salon/          ← サロン内観写真
│   └── staff/           ← スタッフ写真
├── app.py
└── README.md
```

HTML/CSS/JSのみで表示できる構造のため、Flaskなしでも一般的なレンタルサーバーにそのまま設置できます。

## 起動方法（ローカル確認）

```bash
pip install flask
python app.py
```

ブラウザで `http://127.0.0.1:5000` を開いて確認してください。

Flaskを使わず直接 `index.html` をブラウザで開いても表示できますが、
一部のブラウザではローカルファイルのfetch等が制限される場合があるため、
ローカル確認にはFlask経由を推奨します。

## 写真の差し替え

現在はすべて仮画像（プレースホルダー）です。
`<!-- REPLACE: ... -->` というコメントが付いている箇所に、実際の写真を差し替えてください。

- ファーストビュー人物写真: `images/fv/`
- Before/After比較写真: `images/before-after/`（現在1組のみ実装。複数組にする場合はJSの拡張が必要です）
- 製品写真: `images/product/`（マリムーブフェイシャルワックス、ワックスウォーマー等。実際の写真を反映済み）
- 施術・スタッフ写真: `images/treatment/`, `images/staff/`（実際の写真を反映済み）

## お客様の声

実際のお客様の声が集まるまでは「お客様の声が入ります」という仮表示のままにしてあります。
架空の口コミを本番用として掲載しないようご注意ください。

## FAQについて

回答文の一部に `<!-- サロン側確認事項: ... -->` というコメントを残しています。
実際のサロン運用に即した内容をサロン側で確認・確定のうえ、コメントを削除して本文を調整してください。

## 主な機能（Vanilla JavaScript実装）

- FAQアコーディオン
- スムーススクロール（ヘッダー分のオフセット考慮）
- スクロール連動の固定CTA表示制御
- Before / After 比較スライダー（ドラッグ・タッチ・キーボード対応、外部ライブラリ不使用）
- スクロール時のフェードイン演出（Intersection Observer使用、`prefers-reduced-motion` にも配慮）
